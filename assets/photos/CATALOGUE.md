# `assets/photos/` — catalogue

One entry per photograph, written by looking at each frame. Start from [`README.md`](README.md): it has the rules, the public-use statuses, a shortlist by job and a compact index. Search this file for `#### <filename>` rather than reading it whole.

Each entry gives:

- The value to pass in code (in backticks), the pixel size, the shape, the file size, and whether it is a kit default.
- **Public use:** Yes, Check or Avoid ([README](README.md#public-use)).
- **Shows:** what is literally in the frame. Write alt text from this, not from the filename.
- **Setting**, **People**, **Light** and palette.
- **Composition:** where the subject sits, where there is calm space for text, and whether text needs a scrim.
- **Crops:** which ratios hold, with an `object-position` when the focal point is off centre.
- **Mood**, **Best for** and **Cautions** (signage, clutter, near-duplicates, mismatched filenames).
- **Used by:** the `content/` records that reference the photo, where any do.
