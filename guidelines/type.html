The face

Diodrum is the only typeface. Display and body share it.

Six weights ship as TTF. There is no second family for UI, and no italic. Reach for the role tokens (--type-h1, --type-body) rather than composing size and weight by hand.

Latin and Cyrillic

Diodrum. --font-core, --font-display, --font-body all point here.

Arabic

IBM Plex Sans Arabic (300–600). Diodrum has no Arabic glyphs; tokens/rtl.css swaps the stack under [dir="rtl"].

Mono

System mono for tokens, specimen notes and catalog chrome only. Never for guest-facing copy.

Guest text size

--text-scale on html[data-text-size] · spacing and control heights stay in px

Every --text-* size is calc(Npx * var(--text-scale)). The website kit footer offers Default / Large / Larger (md 1 · lg 1.125 · xl 1.25), persisted in localStorage. In-page scale is a convenience; browser zoom to 200% remains the WCAG 1.4.4 path.

--text-2xs / --text-3xs are for eyebrows and catalog specimen notes only. Anything a guest must read is at least --text-sm (--text-xs only for true captions such as “5 min read”). Field hints and errors use --text-xs minimum.
