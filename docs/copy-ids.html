Copy IDs

Every page, section, card and component has a stable reference that starts with ds:. Copy it and paste it into a prompt, a review comment or a ticket, so a person or an agent can find the exact thing you mean.

Scheme version 1Shown as “Copy ID” on hover or keyboard focus

Where to find the control

  • Page: top right of every portal page, next to the breadcrumbs.
  • Section: hover or tab onto any section heading; a small “Copy ID” button appears after it.
  • Catalog card: bottom right of each card on the overview.
  • Component: in the preview toolbar on a component page. Inside the live specimen, hover any part that carries data-ds-id to see a dashed outline and a chip with its ID; click the chip to copy it.

How to resolve an ID

  1. ds:components/editorial/Tile → components/editorial/Tile.jsx, its .prompt.md and .d.ts; the page is docs/component.html?c=Tile.
  2. ds:docs/website-copy-voice#core-principle → the page docs/website-copy-voice.html, scrolled to the element with that id. The markdown behind a docs page is named in its meta line.
  3. ds:page/home/hero → the element with data-ds-id="page/home/hero" in ui_kits/website/.

Rules for authors

  • Every component root carries data-ds-id="<family>/<Name>". Keep it when you refactor; it is the join between the code, the catalog and a prompt.
  • Website mockup sections carry data-ds-id="page/<view>/<slot>". Slots are named for their job (hero, programmes, closing), not their position.
  • Section IDs come from the heading text. Renaming a heading changes its ID, so rename only when the meaning changes.
  • IDs are references, not copy. Never show them to guests.
