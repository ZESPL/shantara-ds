# 10. Rates (RATE)

Part of the [search and AI visibility rules](overview.md). Priorities, owner tags and recorded decisions are in the overview.

Rates appear only on the production tariff page, read from the Keystatic tariff ([SKILL.md §1](../SKILL.md)). The one exception is the organisation's indicative `priceRange` in JSON-LD (RATE-01). This design system holds no rates, currencies or validity dates. The tariff lists any number of currencies; each amount is entered exactly as Shantara's rate sheet gives it and is never converted, rounded or calculated.

- **RATE-01 (P0) [Build]** Rates appear only on the tariff page. Every other page links to it. The one exception is the organisation node's `priceRange` and `currenciesAccepted` in JSON-LD (SCHEMA-03), read from the site record: an indicative range for the business, never an exact rate and never an `Offer`. **Check:** a build step searches `dist/` outside the tariff page for every currency code and symbol in the tariff, and for rate figures, and fails on a match. It skips the organisation node's `priceRange` and `currenciesAccepted`.
- **RATE-02 (P0) [Content]** Each rate states its currency (ISO code) and its unit (per room or per person, per night, and the occupancy), and the page states that rates include all taxes. Amounts appear exactly as entered. It is visible server-rendered text, never an image, tooltip or something that needs a click. A draft tariff is not published. **Check:** `curl` the tariff page. Every rate, currency and unit appears as text.
- **RATE-03 (P0) [Build]** The default currency is the first one in the tariff for every visitor. It never changes with IP address, locale, cookie or device; only the visitor's own choice in the currency selector changes it. Locale is not currency. **Check:** load the tariff page from two countries and two devices. Same default figures.
- **RATE-04 (P1) [Build]** If the tariff page emits JSON-LD `Offer` nodes, each `price` is a plain number that equals the visible figure, with an ISO `priceCurrency` and a `priceSpecification` with `valueAddedTaxIncluded: true`. No other page emits `Offer`. Visible figures carry a `data-rate` attribute so tests can read them. **Check:** an automated test compares each visible `data-rate` value with the JSON-LD price.
- **RATE-05 (P0) [Content]** Nothing Shantara's rate sheet marks internal reaches the site. Only the public all-inclusive rates, supplements, inclusions, exclusions, payment terms and cancellation policy are published. **Check:** before each tariff update, compare the tariff page with the public sections of the rate sheet. Nothing else appears.
