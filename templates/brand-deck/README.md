# Brand deck

HTML presentation template — twelve 1280×720 layouts in the guideline-deck style.

**Deck design rules:** [`.cursor/skills/shantara-premium-presentations/SKILL.md`](../../.cursor/skills/shantara-premium-presentations/SKILL.md)

**Rule of one:** each layout holds one idea, one visual and one focal point; the deck has one audience, one goal and one next step. See [`docs/rule-of-one.md`](../../docs/rule-of-one.md).

Browse it in the catalog under **Templates → Brand deck**. The same rules apply to PowerPoint, Google Slides, Keynote, Canva, and PDF decks — this folder is the HTML starting point only.
